Map Layer & Testimony Simulator

Design map layers (medbay, security, ...) and simulate [LOCATION] testimony from coordinates
Web-only · solo dev · zero build step

1 · Draw map layers

Click-drag to draw a layer  |  Click a layer to select  |  Shift+click canvas to place a sighting
Layers are rectangles. An entity's coordinates fall into the topmost layer that contains them — that's their [LOCATION].

2 · Sightings (who was where, when)

Each sighting is resolved against the map layers: coordinates → layer → [LOCATION] testimony.

3 · Testimony output & export

— — sightings
Draw layers, add sightings, then review generated testimony.
Exported JSON contains your map layers and sightings. Your game's testimony system reads coordinates, finds the containing layer, and emits "I saw [ENTITY] at [LAYER]."
